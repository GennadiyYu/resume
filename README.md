# Резюме по вопросам

Сайт, который собирает резюме по ответам на вопросы. Данные нигде не сохраняются.
Есть фото, выбор города, дата рождения, скачивание в PDF и Word, ИИ-улучшение текста (Gemini).

## Запуск на своём компьютере
1. Установите Node.js 18+.
2. Скопируйте `.env.example` в `.env` и впишите ключ: `GEMINI_API_KEY=ваш_ключ`
3. `npm start`, затем откройте http://localhost:3000

## Размещение в интернете
**GitHub Pages** подходит только для статичных сайтов: там всё, кроме ИИ, работает,
а кнопки «Улучшить с ИИ» нет (нет сервера, а ключ нельзя хранить в открытом коде).

**Чтобы работало всё, включая ИИ:** загрузите репозиторий на GitHub, затем на render.com
создайте Web Service из этого репозитория (Build Command: пусто, Start Command: `npm start`)
и в разделе Environment добавьте переменную `GEMINI_API_KEY`.

Файл `.env` с ключом в репозиторий не попадает (указан в `.gitignore`).
