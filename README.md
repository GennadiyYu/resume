# Конструктор резюме с GroqCloud

Пошаговый конструктор резюме с локальным предпросмотром, улучшением текста через GroqCloud и экспортом в PDF через печать браузера или HTML-совместимый Word (.doc).

## Запуск локально

1. Node.js 22+.
2. Скопируйте `.env.example` в `.env`.
3. Создайте ключ на https://console.groq.com/keys и внесите его в локальный `.env` (никогда не публикуйте его).
4. Запустите `npm start`. Откройте http://localhost:3000 .
5. `npm test` запускает существующие тесты.

## Vercel

Проект связан с репозиторием GitHub и автоматически развёртывается из main. В Vercel → Project → Settings → Environment Variables добавьте:

- `GROQ_API_KEY` — действительный секретный API-ключ из GroqCloud; Production и Preview, скрытый / sensitive.
- `GROQ_MODEL` — `openai/gpt-oss-120b` (необязательно, это значение по умолчанию).

После изменения переменных сделайте Redeploy последнего выпуска. `GET /api/status` возвращает `provider:groq`, `keyConfigured` и имя модели, но **не проверяет действительность ключа**. Проверьте реальную генерацию кнопкой ИИ.

Текст резюме передаётся в GroqCloud при вызове ИИ. Не загружайте чувствительные персональные данные без соответствующих уведомлений и согласий. Для широкого публичного доступа необходимо добавить устойчивый распределённый rate-limit и меры против злоупотребления API.

**Ограничения текущей версии:** DOC-экспорт пока не является настоящим DOCX; PDF формируется через печать браузера. Нет полноценной авторизации и распределённого ограничения запросов.
