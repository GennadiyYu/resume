# Конструктор резюме с Gemini AI — исправленная версия

Возможности:
- Пошаговый ввод данных о кандидате, фотография, предпросмотр;
- ИИ-редактирование разделов «О себе», «Опыт работы», «Навыки»;
- **Новая кнопка «Обработать всё резюме с ИИ»** на последнем шаге;
- Проверка подключения API на экране и понятные сообщения об ошибках;
- PDF через печать браузера → «Сохранить как PDF», Word в формате `.doc` (не `.docx`).

## Что нужно для запуска

1. Установите Node.js 18+ (рекомендуется Node.js 22 LTS).
2. Скопируйте `.env.example` в `.env` в корне проекта.
3. В `.env` замените `ВСТАВЬТЕ_КЛЮЧ_СЮДА` на **ваш действующий ключ Google Gemini**.
4. В терминале в папке проекта запустите `npm start`.
5. Откройте **http://localhost:3000** — не `index.html` напрямую с диска.
6. Внизу формы должен появиться статус `ИИ: сервер подключён, модель ...`. Это означает, что ключ задан, **а не то, что он действителен**. Для проверки отправьте небольшой текст через кнопку ИИ.

Проверить состояние можно по адресу **http://localhost:3000/api/status**. Возвращается `keyConfigured: true/false`; сам ключ не показывается.

## Развёртывание на Render

1. Загрузите файлы проекта в GitHub, **кроме `.env`**.
2. Render → New → **Web Service** → подключите репозиторий.
3. Runtime: Node; Build Command: `npm install`; Start Command: `npm start`.
4. Render → Environment → задайте `GEMINI_API_KEY` = ваш ключ и (по желанию) `GEMINI_MODEL` = `gemini-3.5-flash-lite`.
5. Выполните Deploy и откройте URL веб-сервиса.

**Важно:** GitHub Pages, Render Static Site, загрузка файла `index.html` или открытие через `file://` **не подходят** для ИИ-функций. Нужен Web Service, потому что браузер отправляет запрос на `/api/ai`.

## Частые ошибки

| Ошибка | Причина и действие |
| --- | --- |
| Не задан GEMINI_API_KEY | Запишите действующий ключ в `.env` локально или Environment на хостинге, перезапустите сервер. |
| 404 на /api/ai | Открыт статический сайт, а не Node.js Web Service. |
| Gemini отклонил запрос (400 / 401 / 403) | Проверьте ключ, права, регион сервера; возможно, ключ устарел, заблокирован или ограничен. |
| Модель недоступна (404) | Проверьте `GEMINI_MODEL` и доступность модели для конкретного ключа. |
| Лимит Gemini (429) | Проверьте квоты/биллинг в Google AI Studio. |
| 502, сеть | Сервер не может подключиться к Google API; проверьте исходящие соединения и регион. |
| Истекло время ожидания | Вызов Gemini дольше 45 секунд; повторите или выберите более быструю модель. |

По состоянию на октябрь 2026 года Google ограничивает доступ к старым Gemini 2.5 для новых проектов. Поэтому здесь выставлена современная модель `gemini-3.5-flash-lite`. Точную актуальность доступных моделей и условий смотрите в официальной документации Gemini API.

## Замечания

- Без **реального** действующего ключа невозможно проверить успешную генерацию во внешнем Gemini API. В проекте нет ключа намеренно.
- Данные резюме не сохраняются в базе приложения, но текст обрабатывается внешним сервисом Google.
- PDF создаётся через браузерный диалог печати, а `.doc` — это HTML для Word, не полноценный DOCX. При дальнейшем развитии лучше использовать настоящее PDF/DOCX-формирование.
- Для публичного продукта перед массовым использованием понадобятся авторизация, ограничение частоты запросов, мониторинг расходов, политика обработки персональных данных и защита от злоупотребления API.
